# User Stories

> Working Draft

## Purpose

This document defines the functional requirements for the first implementation of the Commons Protocol.

Each user story describes a capability the application should provide from a participant's perspective.

The stories are organized into epics that can be independently implemented and tested.

---

# Epic: Participant Management

## US-001 Create a profile

As a participant

I want to create my profile

So that other participants know who I am.

---

## US-002 Join a Commons

As a participant

I want to join my local Commons

So that I can participate in its economy.

---

## US-003 Leave a Commons

As a participant

I want to leave my Commons

So that I am no longer an active participant.
