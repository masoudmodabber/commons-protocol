# Purpose

> Working Draft

## Purpose of this Project

The Commons Protocol is an open protocol for organizing voluntary exchange within and between autonomous geographic communities called **Commons**.

Its goal is to provide a framework for communities to coordinate work, services, resources, and mutual assistance while preserving the strengths of free markets and reducing the long term concentration of economic power.

The protocol is independent of any specific application, programming language, database, or technology stack.

Applications are implementations of the protocol.

The protocol itself is the primary project.

---

# Scope

This repository defines:

* The purpose of the protocol.
* The philosophy behind its design.
* The core domain model.
* The rules governing interactions within a Commons.
* The rules governing cooperation between Commons.
* The intended scope of the first implementation.
* Open questions that remain unresolved.

It intentionally avoids implementation details unless they are necessary to explain the protocol itself.

---

# Objectives

The protocol aims to:

* Preserve voluntary exchange.
* Preserve free market price discovery.
* Encourage local autonomy.
* Enable voluntary cooperation between Commons.
* Record reciprocal contribution instead of accumulated wealth.
* Prevent permanent concentrations of economic and political power.
* Remain technology independent.
* Support gradual evolution through experimentation.

---

# Non Objectives

The protocol does not attempt to define:

* A complete political system.
* A national legal system.
* A specific economic policy.
* A user interface.
* A software architecture.
* Database schemas.
* APIs.
* Authentication providers.
* Deployment strategies.

Those concerns belong to individual implementations or future specifications.

---

# Document Guide

This repository is organized into several documents.

* `philosophy.md` explains why the protocol exists and the principles that guide its design.
* `domain/` defines the concepts that make up the protocol.
* `protocol/` defines how independent Commons cooperate.
* `appendix/` contains supporting documents such as the MVP scope and unresolved design questions.

Together, these documents describe the Commons Protocol independently of any particular software implementation.
